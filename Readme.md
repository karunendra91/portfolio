## 🎮 How to Use New Features

### Dark/Light Mode

Click the **moon/sun icon** in the navbar to toggle themes. Your preference is saved automatically!

### Mobile Menu

On small screens, click the **hamburger icon** (☰) to open the menu. Links auto-close the menu.

### Scroll Features

- **Progress Bar**: Colored bar shows your scroll progress
- **Scroll to Top**: Button appears when scrolling - click to jump to top
- **Parallax**: Notice background movement in hero section

### Keyboard Shortcuts

- **Ctrl/Cmd + K**: Toggle mobile menu
- **ESC**: Close mobile menu

## 🔧 Customization

### Change Colors

Edit CSS variables in `style.css` (lines 5-18):

```css
:root {
  --primary-color: #38bdf8;
  --secondary-color: #a78bfa;
  --accent-color: #facc15;
  /* ... more variables ... */
}
```

### Modify Text Animations

Edit `script.js` lines 48-54:

```javascript
strings: [
  "Your Role Here 💻",
  "Another Role 🎨",
  // Add more...
];
```

### Adjust Animation Speed

Find animation properties and change duration:

```css
animation: slideUp 0.6s ease-out; /* Change 0.6s */
```
